# Top10 de Política — Google Trends Em alta

O alerta `politica_google_trends_rss` mantém o ID por compatibilidade, mas a fonte de produção é agora a página pública Google Trends Em alta, Brasil, categoria Política14, últimas24h. O RSS geral tem somente dez entradas e não fornece cobertura suficiente de política nem os detalhamentos dos grupos; não é fallback.

Usa dados públicos renderizados na página (`AF_initDataCallback`, ds:0), sem autenticação, SerpAPI, BigQuery ou IA. A estrutura é validada: mudança de formato, falha HTTP ou ausência de tópicos políticos gera erro explícito, nunca resumo substituído pelo RSS reduzido. Endpoint público não documentado como API estável; precisa monitoramento de compatibilidade.

Seleciona os dez grupos políticos com maior estimativa, desempate por início mais recente e título. Inclui tendências ativas e encerradas na janela24h, como a página. Categoria e todos os termos de cada grupo são fornecidos pelo próprio Google: não cria agrupamentos por mera semelhança de palavras. Lista TODOS os termos, incluindo título, sem cortes, em páginas numeradas de até3900caracteres (blocos extensos continuam na página seguinte). A estimativa é do grupo; não se atribui o volume do grupo a cada variante e não se somam valores. Consultas podem conter alegações; não são afirmações do alerta nem comprovam veracidade, apoio ou voto.

Comparação entre coletas de até48h no namespace `politica_trending_v2`: mostra mudança de posição e faixa estimada anterior do mesmo tópico. Primeira coleta da fonte completa reinicia a base, sem misturar com antigo recorte RSS. Não inventa percentuais próprios nem confunde queda de posição com queda de buscas. Grupos ausentes não são interpretados como queda. Novo termo agrupado muda o conteúdo e pode gerar mensagem.
